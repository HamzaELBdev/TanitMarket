# Vidéo de présentation TanitMarket

`TanitMarket-presentation.mp4` — 52 s, 1920×1080, 30 fps, sans son.

Scènes : intro logo → « Achetez. Vendez. Tout simplement. » → annonces → négociation du prix → 24 gouvernorats → Simple. Local. Gratuit. → appel à l'action.

## Modifier et régénérer
- Ouvrir `index.html` dans un navigateur pour prévisualiser l'animation en boucle.
- Les textes, timings (`SC`, `CUTS`, appels `a(...)`) et styles sont dans `index.html`.
- Régénérer le MP4 : `node render.js` (nécessite Playwright + Chromium, et ffmpeg ; ajuster la constante `FF` dans `render.js`).
